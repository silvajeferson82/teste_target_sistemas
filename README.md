# Desafio Tecnico - Target Sistemas

## desafio_1.ts
Este arquivo contém um código que calcula a soma de todos os números de 1 até um índice `INDICE` utilizando um loop `for`.

## desafio_2.ts
Este arquivo contém uma função que verifica se um número pertence à sequência de Fibonacci. A função itera através da sequência até encontrar o número ou ultrapassá-lo, retornando uma mensagem apropriada.

## desafio_3.ts
Este arquivo contém funções para ler dados de faturamento diário de um arquivo JSON, calcular estatísticas como o menor e maior valor de faturamento, a média mensal e o número de dias com faturamento acima da média, e exibir esses resultados.

## desafio_4.ts
Este arquivo contém uma função que calcula o percentual de representação de cada estado dentro do valor total mensal de faturamento da distribuidora. Os percentuais são calculados e exibidos com duas casas decimais.

## desafio_5.ts
Este arquivo contém uma função que inverte uma string. A função recebe uma string como entrada e retorna a string invertida.

## Como Rodar o Projeto

### Pré-requisitos
- Node.js (versão 14 ou superior)
- npm (gerenciador de pacotes do Node.js)
- yarn (opcional, mas recomendado para instalação)
- TypeScript (versão 4 ou superior)

### Instalação
1. Clone o repositório:
  ```bash
  git clone https://github.com/silvajeferson82/teste_target_sistemas.git
  ```
2. Navegue até o diretório do projeto:
  ```bash
  cd teste_target_sistemas
  ```
3. Instale as dependências:
  ```bash
  npm install
  ```

### Executando os Desafios
Para executar cada um dos desafios, utilize os seguintes comandos:

- **desafio_1.ts**:
  ```bash
  npx ts-node src/desafio_1.ts
  ```

- **desafio_2.ts**:
  ```bash
  npx ts-node src/desafio_2.ts
  ```

- **desafio_3.ts**:
  ```bash
  npx ts-node src/desafio_3.ts
  ```

- **desafio_4.ts**:
  ```bash
  npx ts-node src/desafio_4.ts
  ```

- **desafio_5.ts**:
  ```bash
  npx ts-node src/desafio_5.ts
  ```
